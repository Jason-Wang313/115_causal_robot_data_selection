# Hostile Prior Work

The hostile set contains 100 papers from the shared robotics literature pool. The strongest threats are causal data selection, invariant learning, active learning, client/data selection, and robot foundation-model data curation:

- Adaptive Client Selection in Resource Constrained Federated Learning Systems: A Deep Reinforcement Learning Approach (2021)
- Images Speak Louder than Words: Understanding and Mitigating Bias in Vision-Language Model from a Causal Mediation Perspective (2024)
- SmolVLA: A Vision-Language-Action Model for Affordable and Efficient Robotics (2025)
- Domain-Generalizable Emotion Recognition via Invariant Explanations (n.d.)
- Systematic evaluation of foundation model interpretability and spurious signal (n.d.)

## Novelty Pressure

Generic active learning, label balancing, and invariant-risk objectives are crowded. The defensible contribution is narrower: choose robot data by whether it separates action-critical causal mechanisms that matter for control outcomes.

## Evidence Boundary

The local benchmark supports this boundary against random, label-balanced, diversity, failure-mining, uncertainty, influence, and invariant-risk selectors. It does not settle real hardware generality.
