# Novelty Decision

Decision: `STRONG_REVISE`

The v5 package has a defensible local novelty boundary: select robot data by interventional mechanism value and test it against strong data-selection baselines under hard mechanism/spurious shift.

The novelty is not sufficient for ICLR-main readiness because the evidence remains local/synthetic and lacks real robot or accepted high-fidelity validation, released selected indices, downstream policy checkpoints, calibrated logs, and videos.
